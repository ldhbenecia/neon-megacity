# 미래 서울 한강 (HANGANG) 설계 문서

이 문서는 도시를 가상 도시 "람하"에서 **미래 서울의 나이트시티 "한강"**으로 옮기기 위한 기준이다. 조사한 사실, 그 사실을 게임 좌표로 옮기는 규칙, 설계 결정과 근거, layout v2 → v3 이행 계획을 담는다. 미감과 수치 기준(색, 노출, 창 점등, 성능 예산)은 계속 `docs/ART_DIRECTION.md`를 따르고, 지리와 구역 구성은 이 문서가 우선한다.

- 단위: 1 = 1 m, Y가 위, 지면 y = 0, 북쪽 = -Z, 동쪽 = +X (ART_DIRECTION과 같다).
- 위경도는 WGS84 십진수다. "약"이 붙은 좌표는 지도 판독값이라 ±0.003°(약 300 m) 오차를 가정한다. v3 구현 PR에서 공개 지도(OpenStreetMap 등)로 한 번 더 맞춘다.
- 표기 원칙: 실제 서울 지리(지명, 대교, 지역구, 산, 도로명)는 쓴다. 실존 브랜드, 기업 로고, 상호, 실존 건물의 고유 이름과 정확한 형태는 쓰지 않는다. 한자는 쓰지 않는다.

## 1. 조사

### 1.1 한강 본류 (서울 구간)

- 서울 구간 한강의 평균 폭은 약 1.2 km이고 잠실대교 부근은 약 870 m로 좁아진다. 하상폭(강바닥 전체)은 1~1.5 km, 실제 물이 흐르는 유수폭은 300~1000 m다. [S6][S7][S8]
- 강은 서쪽(하류, 가양·마포)에서 크게 북서로 올라가고, 여의도에서 용산·이촌 앞까지 남동으로 내려가 동작대교 부근에서 가장 남쪽에 닿는다. 다시 북동으로 올라 한남·옥수·성수 앞에서 가장 북쪽에 닿고, 잠실 앞에서 한 번 남쪽으로 처졌다가 광진·천호 쪽으로 다시 북동으로 꺾인다. 아래 표의 대교 위치가 이 굽이를 그대로 보여 준다.
- 잠실 수중보 상류와 하류는 수심과 물결이 다르다(수중보 하류는 1~2 m로 얕은 구간이 있다). [S9]

### 1.2 섬

서울시 자료는 한강의 섬을 8개(난지도, 여의도, 뚝섬, 노들섬, 서래섬, 세빛섬, 밤섬, 선유도)로 든다. [S10]

| 섬     | 위치                                        | 규모와 특징                                                                                                                                    |
| ------ | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 여의도 | 영등포구. 본류 남쪽, 남쪽은 샛강으로 갈라짐 | 원래 큰 모래섬이었고 지금은 금융·방송·국회가 있는 업무지구다. 서강·마포·원효대교가 북쪽에서 닿는다. [S10]                                      |
| 밤섬   | 여의도와 마포 사이, 서강대교 아래           | 약 279,500 m², 외곽 약 2.9 km. 1968년 폭파 뒤 퇴적으로 다시 커졌다. 생태경관보전지역이라 출입 통제, 밤에는 불빛이 없는 숲과 습지다. [S11][S12] |
| 노들섬 | 용산구, 한강대교가 섬을 지나감              | 옛 이름 중지도. 2019년 음악 중심 복합문화공간이 됐다. [S10][S13][S14]                                                                          |
| 서래섬 | 반포 쪽 남안, 동작대교와 반포대교 사이      | 남안에 붙은 길쭉한 인공섬. 봄 유채꽃, 가을 메밀꽃. [S15]                                                                                       |

### 1.6 도로

- 서울 자동차 전용도로는 11개 노선, 총 165.02 km다(2020년 기준). [S30] 도시고속도로 8개 축은 강변북로, 올림픽대로, 내부순환로, 동부간선, 북부간선, 서부간선, 경부고속도로, 서울외곽순환이다. [S31]
- **강변북로**: 강 북안, 천호대교 북단에서 난지도 시계까지 26.8 km. [S30] 고가와 지상 구간이 섞여 있다.
- **올림픽대로**: 강 남안 전 구간을 따라가는 자동차 전용도로.
- **내부순환로**: 성산대교 북단에서 북쪽으로 돌아 성수동까지 이어지는 고가 위주 도로. 성산대교 북단~성수동 22.0 km. [S32]
- **간선**: 테헤란로(강남역~삼성역, 동서), 강남대로(한남대교 남단~강남역, 남북), 세종대로(광화문~서울역, 남북), 종로(광화문~동대문, 동서), 마포대로(마포대교 북단~공덕), 한강대로(서울역~한강대교 북단), 영동대로(영동대교 남단~삼성역), 올림픽로(잠실).
